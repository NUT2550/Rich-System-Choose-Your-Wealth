## 📖 เกี่ยวกับเกม

เกมนี้ได้รับแรงบันดาลใจมาจากนิยายแนว "System" ที่ตัวเอกได้รับพลังวิเศษมาช่วยในการใช้ชีวิต ในเกมนี้คุณจะได้รับบทเป็นตัวเอกที่เพิ่งได้รับ "ระบบ" และต้องเลือกว่าจะใช้ระบบแบบไหนในการดำเนินชีวิตและสร้างฐานะ

## ✨ ฟีเจอร์หลัก

### 🎛️ ระบบเลือกเส้นทาง (Choose Your System)
เกมมีระบบให้คุณเลือก 3 เส้นทาง (จากทั้งหมด 4 เส้นทาง) แต่ละเส้นทางให้ประสบการณ์การเล่นที่แตกต่างกัน:

| ระบบ | รายละเอียด |
|------|-----------|
| 🔄 **[1] ระบบเงินคืน (Cashback)** | ยิ่งใช้ ยิ่งรวย! ใช้เงิน 100 บาท ได้เงินคืน 200 บาท (เข้าหลัง 5 วินาที) |
| ⏱️ **[2] ระบบรายได้วินาที (Idle Income)** | นั่งนิ่งๆ ก็มีเงินเข้าทุกวินาที พร้อมระบบอัปเกรดเพิ่มรายได้อัตโนมัติ |
| 🏛️ **[3] ระบบเงินไม่จำกัด (Story Focus)** | เงินไม่จำกัด แต่เน้นการปลดล็อกเนื้อเรื่องและเหตุการณ์ VIP สุดพิเศษ |
| ❤️ **[4] ระบบเปย์คนสนิท** | *(กำลังพัฒนา เร็วๆ นี้)* |

### 🛍️ ระบบร้านค้าและสินค้า
เลือกซื้อสินค้าหรูหราตั้งแต่กาแฟราคาหลักร้อย ไปจนถึงนาฬิกาหรูราคาหลักหมื่น!
- ☕ กาแฟหรู (100 บาท)
- 🍽️ อาหารร้านดัง (500 บาท)
- 👜 กระเป๋าแบรนด์ (2,000 บาท)
- ⌚ นาฬิกาหรู (5,000 บาท)

### 📱 ระบบจำลองชีวิตสมจริง
- **หน้าต่างระบบ:** รับข้อความแจ้งเตือนจากระบบ (Style นิยาย)
- **SMS มือถือ:** จำลองข้อความธนาคารแจ้งเข้า-ออก
- **เหตุการณ์พิเศษ:** ปลดล็อก Achievement และเนื้อเรื่องเมื่อทำภารกิจสำเร็จ
